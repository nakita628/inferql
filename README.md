# InferQL

Typed SQL for TypeScript: `sql('SELECT ...')` runs the query and returns rows typed from your
`.sql` migrations, and an oxlint rule checks every query against the real database.

| Package                                     | Description                                           |
| ------------------------------------------- | ----------------------------------------------------- |
| [`inferql`](packages/inferql)               | The library: `connect`, type inference, the lint rule |
| [`vscode-inferql`](packages/vscode-inferql) | The VS Code extension: SQL completion at the cursor   |
